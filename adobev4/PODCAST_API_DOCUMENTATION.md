# Podcast API Documentation

## Overview

The Podcast API provides two powerful endpoints for generating and downloading AI-powered podcasts using Azure TTS (Text-to-Speech). The API integrates with your document analysis system to create engaging podcast content based on your queries and indexed documents.

## Featur

- **Azure TTS Integration**: High-quality neural voice synthesis
- **Two-Speaker Dialogue**: Alex (host) and Dr. Sharma (expert) personas
- **Document-Based Content**: Podcasts generated from your indexed documents
- **Two Generation Modes**: Generate-and-store or generate-and-download
- **Automatic Cleanup**: Background tasks clean up temporary files
- **Unique File Management**: UUID-based filenames prevent conflicts

## Endpoints

### 1. Generate Podcast and Get Filename

**Endpoint**: `POST /podcast/generate`

**Description**: Generates a podcast from a query and returns the filename for later download.

**Request**:
```bash
curl -X POST -F "query=what are the latest discoveries on Mars" http://127.0.0.1:8000/podcast/generate
```

**Response**:
```json
{
  "status": "success",
  "message": "Podcast generated successfully.",
  "filename": "podcast_1234abcd-5678-efgh-ijkl-mnopqrstuvwx.mp3",
  "download_url": "/audio/podcast_1234abcd-5678-efgh-ijkl-mnopqrstuvwx.mp3"
}
```

**Use Case**: When you want to generate the podcast first and download it later, or when you need to share the download link with others.

### 2. Generate and Download Podcast Directly

**Endpoint**: `GET /podcast/download`

**Description**: Generates a podcast from a query and immediately streams the audio file for download.

**Request**:
```bash
# Using curl (with proper URL encoding)
curl -o mars_podcast.mp3 "http://127.0.0.1:8000/podcast/download?query=what%20are%20the%20latest%20discoveries%20on%20Mars"

# Alternative curl command (spaces replaced with %20)
curl -o mars_podcast.mp3 "http://127.0.0.1:8000/podcast/download?query=what%20are%20the%20latest%20discoveries%20on%20Mars"

# Direct browser access (browser will handle encoding automatically)
http://127.0.0.1:8000/podcast/download?query=what are the latest discoveries on Mars
```

**Response**: Direct audio file download with filename like `podcast_for_what_are_the_latest.mp3`

**Use Case**: When you want immediate download without storing the file on the server.

### 3. Download Generated Audio File

**Endpoint**: `GET /audio/{filename}`

**Description**: Downloads a previously generated audio file by filename.

**Request**:
```bash
curl -o my_podcast.mp3 "http://127.0.0.1:8000/audio/podcast_1234abcd-5678-efgh-ijkl-mnopqrstuvwx.mp3"
```

**Use Case**: Download files generated by the `/podcast/generate` endpoint.

## Configuration

### Azure TTS Settings

The API uses Azure Cognitive Services for text-to-speech. Ensure these settings are configured in `app.py`:

```python
# TTS Provider
TTS_PROVIDER = "azure"

# Azure Configuration
AZURE_SPEECH_KEY = "your_azure_speech_key"
AZURE_SPEECH_REGION = "centralindia"  # or your preferred region
```

### Voice Selection

The API uses two neural voices:
- **Alex (Host)**: `en-US-DavisNeural` (Male voice)
- **Dr. Sharma (Expert)**: `en-US-NancyNeural` (Female voice)

## How It Works

### 1. Content Generation Process

1. **Query Analysis**: The system analyzes your query using semantic search
2. **Document Retrieval**: Relevant passages are retrieved from your indexed documents
3. **AI Analysis**: Gemini AI categorizes and analyzes the retrieved content
4. **Script Generation**: A conversational podcast script is created with Alex and Dr. Sharma
5. **Audio Synthesis**: Azure TTS converts the script to high-quality audio
6. **File Management**: Audio is saved and made available for download

### 2. File Management

- **Storage**: All generated audio files are stored in the `audio/` directory
- **Naming**: Files use UUID-based names to prevent conflicts
- **Cleanup**: Direct download files are automatically cleaned up after download
- **Persistence**: Generated files (from `/podcast/generate`) remain available until manually deleted

## Error Handling

### Common Error Responses

**400 Bad Request**: Invalid query or missing parameters
```json
{
  "detail": "Podcast generation failed at the audio stage."
}
```

**404 Not Found**: Audio file not found
```json
{
  "detail": "Audio file not found"
}
```

**500 Internal Server Error**: Generation or processing error
```json
{
  "detail": "Failed to generate podcast audio."
}
```

### Troubleshooting

1. **Azure TTS Errors**: Check your Azure Speech service credentials and region
2. **Document Index Issues**: Ensure documents are properly indexed using the `/add` endpoint
3. **File Permission Issues**: Verify the `audio/` directory is writable
4. **Memory Issues**: Large document collections may require more server memory

## Integration Examples

### Frontend Integration

```javascript
// Generate podcast and get download link
async function generatePodcast(query) {
    const formData = new FormData();
    formData.append('query', query);
    
    const response = await fetch('/podcast/generate', {
        method: 'POST',
        body: formData
    });
    
    const result = await response.json();
    return result.download_url;
}

// Direct download
function downloadPodcast(query) {
    const url = `/podcast/download?query=${encodeURIComponent(query)}`;
    window.open(url, '_blank');
}
```

### Python Integration

```python
import requests

# Generate podcast
response = requests.post(
    'http://127.0.0.1:8000/podcast/generate',
    data={'query': 'What are the benefits of AI in healthcare?'}
)
result = response.json()
download_url = result['download_url']

# Download the file
audio_response = requests.get(f'http://127.0.0.1:8000{download_url}')
with open('podcast.mp3', 'wb') as f:
    f.write(audio_response.content)
```

## Performance Considerations

- **Generation Time**: Podcast generation typically takes 30-60 seconds depending on content length
- **File Size**: Generated MP3 files are typically 1-5 MB for 2-3 minute podcasts
- **Concurrent Requests**: The API can handle multiple concurrent requests
- **Storage**: Monitor the `audio/` directory size and clean up old files periodically

## Security Notes

- **File Access**: Generated audio files are publicly accessible via the `/audio/{filename}` endpoint
- **Query Validation**: Consider implementing query validation and rate limiting for production use
- **Authentication**: Add authentication middleware for production deployments
- **File Cleanup**: Implement a scheduled cleanup task for old audio files

## Future Enhancements

- **Custom Voices**: Allow selection of different Azure TTS voices
- **Podcast Templates**: Pre-defined podcast formats and styles
- **Batch Processing**: Generate multiple podcasts from a list of queries
- **Audio Formats**: Support for different audio formats (WAV, OGG, etc.)
- **Podcast Metadata**: Include episode information, duration, and transcript
